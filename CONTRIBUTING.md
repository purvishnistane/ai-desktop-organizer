# Contributing

1. Create a focused branch from `main`.
2. Keep filesystem operations safe, reversible, and covered by tests.
3. Run backend tests with `cd backend && pytest -q`.
4. Run frontend tests and the production build with `cd frontend && npm test && npm run build`.
5. Do not commit `.env`, databases, dependency folders, generated output, or user files.
6. Open a pull request with a concise summary, test evidence, and screenshots for UI changes.
