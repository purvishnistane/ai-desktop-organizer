Installation:
1. cd backend && python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
2. uvicorn app.main:app --reload --port 8000
3. In another terminal, cd frontend && npm install && npm run dev
4. Open the Vite URL and scan the included demo_files folder.
